# 新手教程关设计

> 目标：让玩家在 **3 分钟内**不靠文字说明就学会全部基础操作与核心战斗。
> 设计原则：**先安全练习，再用怪物实战，每次只引入一个新概念。**

---

## 一、结构总览

横向 2400px（主关卡 960px 的 2.5 倍），分 **5 个教学段**，每段一台「教学牌坊」提示按键。

```
 起点                                                              终点
  │                                                                  │
  ├─ ① 走/跳 ──② 轻攻击──③ 重攻击──④ 闪避──⑤ 综合 ───────────────▶ BOSS 房
  │  无怪        苔团×1     石守×1     苔团×2      灯笼虫+苔团+石守
  │
  安全地台      单怪隔离    重甲教学    闪避实战     三敌同场
```

| 段 | 位置 | 教什么 | 怪物 | 为什么这么设计 |
|---|---|---|---|---|
| **① 移动** | x 0~500 | 走、跑、跳、二段平台 | **无** | 第一个怪之前必须有安全区，否则新手一进场就被打 |
| **② 轻攻击** | x 500~900 | 四连轻击、连击条 | 苔团 ×1 | 苔团前摇 0.42s 最长、血最薄，是唯一适合"站着打"的敌人 |
| **③ 重攻击** | x 900~1400 | 重击三连、破霸体 | 石守 ×1 | 石守有霸体，轻攻击打不断它抡砸 → **必须用重击**才知道区别 |
| **④ 闪避** | x 1400~1900 | 闪避、无敌帧、子弹时间 | 苔团 ×2 | 两只会同时冲撞，逼玩家学会用无敌帧穿过去 |
| **⑤ 综合** | x 1900~2400 | 全机制组合 | 灯笼虫+苔团+石守 | 三种威胁同场，为 BOSS 做预演 |

**关键设计**：第 ③ 段用**石守**而不是"更硬的苔团"。因为石守的霸体机制逼玩家发现"轻击无效、重击才打断"——这是原设计里重攻击的唯一存在理由，必须教会。

## 二、关卡几何

地面统一在 y=480（与主关卡一致，保持手感）。

### ① 移动段（x 0~500）
```
y=310                          ┌────┐ 台阶 3
                     ┌────┐    │    │
            ┌────┐   │    │    └────┘
   ┌────┐   │    │   └────┘
   │    │   └────┘
═══╧════╧═══╧════╧═══════════════════ 地面 y=480
   120   220  320  420
```
- 三级台阶（高 40px、间隔 100px）—— 这个间距略小于跳跃极限，**新手一次就能上去**
- 台阶顶部宽 72px，站稳不难
- 没有怪物、没有坑

### ② 轻攻击段（x 500~900）
```
                                 ┌──┐ 单向平台
   ═══════════════════════        │  │
                                  苔团
═══╧═══════════════════════════════╧══
```
- 平地，一个苔团站在 x=680
- 背景有一块单向平台（可选上去，教"上跳穿平台"）

### ③ 重攻击段（x 900~1400）
```
        ┌────────┐
        │  石守  │   ← 站在一个 60px 高的台子上
   ─────┴────────┴─────
═══╧═══════════════════╧══════════════
```
- 石守站在抬高的台子上（y=420），玩家在地面需要跳上去或从下方打
- 台子高 60px，玩家身高 48px，**跳上去正好能打到**

### ④ 闪避段（x 1400~1900）
```
   苔团A              苔团B
═══╧═══════════════════════╧═══════════
         ↑ 中间是开阔地，两只从两侧夹击
```
- 两个苔团相距 300px，玩家从中间穿过
- 地面平坦，适合闪避冲刺

### ⑤ 综合段（x 1900~2400）
```
                    灯笼虫（空中）
       苔团   石守
═══╧══════════════════════════════╧════
```
- 三敌密集（x 2050/2150/2250）
- 结尾是通往 BOSS 房的门（本切片里直接接主关卡）

## 三、教学提示 UI

每段入口处一个**牌坊式提示牌**（世界内的 Sprite，不是 UI 层），
玩家走近时在屏幕下方弹出按键提示。

| 段 | 提示内容 | 触发条件 |
|---|---|---|
| ① | `A / D 移动   空格 跳跃` | 进入 x 0~200 |
| ② | `J 连点：轻攻击四连` | 进入 x 500~700 |
| ③ | `L：重攻击   （轻攻击打不断石守）` | 进入 x 900~1100 |
| ④ | `K：闪避   闪避瞬间无敌` | 进入 x 1400~1600 |
| ⑤ | `三种敌人同场 —— 用上你学的全部` | 进入 x 1900~2100 |

**为什么用世界内提示牌而不是纯 UI**：
牌坊在场景里能被看到，玩家会主动朝它走；纯 UI 弹窗容易被忽略或觉得烦。

## 四、美术方向

教程关用**黄昏暖调**，与主关卡的深夜冷调形成对比：

| 元素 | 主关卡（守夜人房） | 教程关 |
|---|---|---|
| 天空 | 夜色远 `#1B2244` → 夜色近 `#3D5385` | **暖橙紫** `#4A3A5E` → `#7A5FA8` |
| 远景 | 冷蓝山 | 紫灰山 + **远塔剪影**（暗示目的地） |
| 地面 | 冷灰石 | 暖褐石（加一点橙调） |
| 装饰 | 紫藤、灯笼 | **芦苇、纸灯、晾晒的布** |

**为什么是黄昏**：教程是"出发"，主关卡是"抵达"。色调差暗示玩家已经走了一段路。

**远塔剪影**：教程结尾能看到远处的塔（主关卡所在），给出"要去那里"的目标感。

## 五、与主关卡的关系

本切片里，教程关结尾直接接主关卡（同一场景内横向延伸），
而不是做成独立场景——因为：

1. 现在没有场景切换系统，做独立场景要额外写加载/过渡
2. 横向延伸让"走过去"这件事有连续性，符合横版动作的直觉
3. 存档只需记一个位置，不用记"在哪个场景"

**以后要拆成独立场景**时，把 `ROOM_W` 拆成两个场景 + 一个 `transition` 节点即可，
教程关的几何数据可以原样复用。
